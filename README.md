# RVHR-ObjectDetection
Repository for the Python Code for Object Detection on RVHR Images
Includes dataset generation, training and inference.

## Setting up the environment
1.  Install requirements.txt file
2.  Install pytorch - ideally with GPU capacity
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
3.  Install editable project
    pip install -e .
